06

install.sh, and why you can read it first

Piping curl into bash has a bad reputation that is partly deserved. Eight properties make this one worth trusting, and the first is that we show you how to read it before running it.

# read it first
curl -fsSL https://caraka.dev/install.sh | less
# see the plan without changing anything
curl -fsSL https://caraka.dev/install.sh | bash -s -- --dry-run
# pin a version for a reproducible environment
CARAKA_VERSION=0.4.0 curl -fsSL https://caraka.dev/install.sh | bash
