Animasi di GitHub, tanpa GIF

GitHub membuang <script> dan <style> dari markdown, tapi gambar dilewatkan apa adanya. Jadi animasinya dititipkan di dalam SVG, pakai SMIL — <animate> dan <animateTransform>, markup gerak bawaan SVG yang tidak butuh stylesheet sama sekali. Ukurannya kecil, tajam di layar retina, dan tidak ada GIF 4 MB yang harus di-render ulang tiap ganti kata.

Satu batasan yang menentukan bentuknya: font eksternal tidak ikut termuat — SVG dirender pakai font milik pembaca. Makanya aksara ꦕ tidak dipakai di dalam banner (di Windows sering jadi kotak kosong); lambangnya dibangun dari geometri cincin yang sudah jadi motif situs, dan teksnya cuma mono dan sans generik. Aksara tetap ada di badan README, tempat GitHub menanganinya sebagai teks biasa.

What it is

Coding agents are locked to one terminal on one machine. Caraka is the missing transport — a thin bridge, not another assistant.

It has no agent loop, no tools, no model provider, and no plugin marketplace. Your coding agent already has all of those, and its versions are better. Caraka adds only what chat needs — identity, sessions, approvals, memory, and audit.

Try it (soon)

npx caraka up # start the envoy

No agent installed? init offers the free path: Gemini CLI, 1,000 requests a day, no card.

YANG PERLU DIINGAT

Buang akhiran .txt saat menaruh berkasnya di repo. Markdown-nya sudah menunjuk ke assets/banner.svg, jadi tidak ada yang perlu disesuaikan lagi.

Pakai path relatif di markdown, bukan URL raw.githubusercontent — path relatif ditulis ulang GitHub jadi URL satu origin dan disajikan langsung, sehingga animasinya jalan. URL ke host lain lewat proksi gambar camo, dan animasinya tidak selamat.

Kartu ini gelap di kedua tema GitHub, jadi tidak perlu dua berkas <picture>.

Animasi mulai ulang tiap gambar dimuat, jadi bagian intronya selalu terlihat oleh pengunjung baru — sisanya loop pelan supaya tidak mengganggu saat orang membaca.

npm tidak menampilkan gambar berpath relatif. Diagram teks polos sengaja disimpan di <details> supaya pembaca npm tetap kebagian.
