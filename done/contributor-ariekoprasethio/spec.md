# Contributor ariekoprasethio

Rama meminta pencantuman contributor di kedua README serta akses GitHub baca/tulis.

Ruang lingkup: `README.md`, `README.id.md`, dan collaborator `CarakaDev/caraka`.
Tidak dikerjakan: perubahan runtime, situs, versi paket, atau akses organisasi.

- **AC-1** WHEN pembaca membuka salah satu README, dokumen shall menampilkan `ariekoprasethio` dengan tautan profil GitHub.
- **AC-2** WHEN undangan collaborator dibuat, GitHub shall mencatat izin `write` untuk `ariekoprasethio`.
- **AC-3** WHILE undangan belum diterima, laporan hasil shall menyatakan bahwa akses tulis masih menunggu penerimaan.
- **AC-4** WHEN perubahan diterbitkan, branch `main` shall memuat kedua penambahan README.
