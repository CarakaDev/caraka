# Store listing — Caraka (Google Play)

## en-US (default)

**App name (≤30):** Caraka

**Short description (≤80):**
Send tasks to the coding agent on your own computer, and approve its steps.

**Full description:**
Caraka connects your phone to the coding agent that already runs on your computer or server, such as Claude Code or Codex. You send the task. The agent does the work on your machine. Caraka carries the messages between you.

What you can do:
• Pair the phone with your Caraka server once, with a short-lived link or QR code.
• Start a session in a workspace and follow the answer as it grows.
• Approve or reject each risky step with one tap. A typed word never counts as approval.
• Send screenshots, PDFs, and other files to the agent, up to 20 MB.
• Open what the agent sends back: images, Markdown (rendered or source), PDF, audio, and video.
• Stop a run at any time.
• See every paired device and remove one.

What Caraka is not:
• It is not an AI model and it has no agent of its own.
• It has no account and no cloud of ours. The app talks only to the address you pair it with.

Requirements:
• Caraka 1.6 or newer running on your computer or server, with the Web channel turned on.
• An HTTPS address for that server, for example Tailscale Serve or a named Cloudflare Tunnel. Setup guide: https://caraka.dev/guide

Caraka is open source under the MIT license. Its status is "unproven": the code ships, and field checks on real phones are still in progress.

**Deskripsi lengkap:**
Caraka menghubungkan HP-mu ke coding agent yang sudah berjalan di komputer atau servermu, misalnya Claude Code atau Codex. Kamu kirim tugasnya. Agent bekerja di mesinmu. Caraka membawa pesannya.

• Kirim tangkapan layar, PDF, dan berkas lain ke agent, sampai 20 MB.
• Buka berkas dari agent: gambar, Markdown (tampilan atau sumber), PDF, audio, dan video.

Yang bukan Caraka:
• Caraka bukan model AI dan tidak punya agent sendiri.

Syarat:
• Caraka 1.6 atau lebih baru berjalan di komputer atau server, dengan channel Web aktif.
• Alamat HTTPS untuk server itu, misalnya Tailscale Serve atau Cloudflare Tunnel bernama. Panduan: https://caraka.dev/guide

Caraka open source dengan lisensi MIT. Statusnya "unproven": kodenya sudah rilis, dan uji lapangan di HP nyata masih berjalan.

## Data safety (draft answers)

- The developer runs no server. The app sends messages and files only to the server address that the user pairs. That server belongs to the user.
- Data collected by the developer: none. Data shared with third parties: none.
- Encryption in transit: yes, HTTPS only on release builds.
- Data deletion: "Disconnect" deletes all local data. The user's own server holds the history.
- Google code scanner runs on the device through Google Play services.
